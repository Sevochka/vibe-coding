# AI Sprint X2 - Клон сайта

Точная копия лендинга курса AI Sprint X2 по изучению искусственного интеллекта в маркетинге и продажах.

## Описание

Этот проект представляет собой полный клон официального сайта AI Sprint X2 - онлайн-курса с ежедневной практикой, Zoom-разборами и поддержкой куратора. Сайт создан с использованием современных веб-технологий и точно воспроизводит дизайн и функциональность оригинала.

## Особенности

### Дизайн и визуал
- ✨ Точное воспроизведение оригинального дизайна
- 🎨 Градиентные фоны и современная цветовая схема
- 📱 Полностью адаптивная верстка для всех устройств
- 🌟 Анимации и интерактивные эффекты
- 🎪 Плавные переходы и hover-эффекты

### Функциональность
- 📋 Интерактивное FAQ с аккордеон-меню
- 🚀 Плавная прокрутка по якорным ссылкам
- 💫 Модальные окна для регистрации на курс
- 📊 Индикатор прогресса прокрутки страницы
- 🎯 Анимации появления элементов при скролле
- 📱 Оптимизация для touch-устройств

### Секции сайта
- 🏠 **Главная секция** с основной информацией о курсе
- 🎯 **Целевая аудитория** - кому подходит курс
- 📝 **Задачи курса** - что решает обучение
- 🎓 **Программа обучения** - чему научитесь
- 📚 **Формат обучения** - как проходят занятия
- 👥 **Команда** - преподаватели и кураторы
- 💼 **Кейсы** - примеры внедрения AI
- ⭐ **Отзывы** учеников курса

- 📞 **Поддержка** - контактная информация

### Технические особенности
- 🔧 Vanilla JavaScript без зависимостей
- 💎 Современный CSS с Flexbox и Grid
- 🎨 CSS переменные для удобной кастомизации  
- ⚡ Оптимизированная производительность
- 📐 Максимальная ширина 660px согласно требованиям
- 🔄 Автоматическое изменение размера iframe

## Технологии

- **HTML5** - семантическая разметка
- **CSS3** - стили с современными возможностями
- **JavaScript** - интерактивность и анимации
- **Intersection Observer API** - анимации при скролле
- **ResizeObserver API** - автоматическое изменение размера
