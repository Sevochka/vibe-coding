# Свадебная презентация "Детские воспоминания"

## Описание

Интерактивная свадебная презентация с викториной о детстве жениха и невесты. Каждый из 19 вопросов размещен на отдельном слайде с красивой анимацией и современным дизайном в стиле Sports.ru.

## Возможности

### Интерактивная навигация
- Навигация между слайдами с помощью кнопок "Назад" и "Далее"
- Управление с клавиатуры (стрелки влево/вправо)
- Поддержка свайпов на мобильных устройствах
- Прогресс-бар с отображением текущего прогресса

### Дизайн и анимации
- Современный дизайн в стиле Sports.ru с брендовыми цветами
- Плавные анимации переходов между слайдами
- Анимированные иконки для каждого вопроса
- Адаптивный дизайн для всех устройств

### 19 вопросов о детстве
1. Рецепт любимого домашнего блюда из детства
2. Кем хотел(а) стать в детстве
3. Кружки и секции в детстве
4. Памятное путешествие из детства
5. Яркие школьные выступления
6. Что чаще всего просил(а) купить в детстве
7. Любимая игрушка в раннем детстве
8. Любимый мультфильм
9. Легкий школьный предмет
10. Любимая книга детства
11. Занятие на летних каникулах
12. Любимый вид спорта в детстве
13. Олимпиады и конкурсы в школе
14. Лучший друг детства
15. Смешное происшествие на семейном празднике
16. Запоминающиеся летние каникулы
17. Детские шалости с друзьями
18. Влиятельный учитель
19. Яркие детские дни рождения

### Технические особенности
- Полностью адаптивный дизайн (максимальная ширина 660px)
- Поддержка полноэкранного режима (F11)
- Предзагрузка слайдов для плавной работы
- Автоматическое изменение размера iframe
- Кроссбраузерная совместимость

### Управление
- **Кнопки**: "Назад", "Далее", "Начать викторину", "Начать заново"
- **Клавиатура**: ← → (навигация), Esc (в начало), F11 (полный экран)
- **Мобильные устройства**: свайпы влево/вправо
- **Прогресс**: визуальный индикатор прогресса и счетчик слайдов

### Структура презентации
1. **Титульный слайд** - приветствие и начало викторины
2. **19 слайдов с вопросами** - каждый вопрос на отдельном слайде
3. **Финальный слайд** - завершение викторины

Идеально подходит для проведения свадебных викторин, развлечения гостей и создания теплой атмосферы воспоминаний о детстве молодоженов.
