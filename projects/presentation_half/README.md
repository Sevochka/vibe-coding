# Элегантная свадебная презентация "Детские воспоминания"

## 🎭 Описание

Изысканная интерактивная свадебная презентация с элегантным дизайном в стиле премиум-презентаций. Каждый из 19 вопросов о детстве жениха и невесты представлен на отдельном слайде с профессиональной типографикой, плавными анимациями и современным интерфейсом.

## ✨ Дизайн и стиль

### Цветовая палитра
- **Основные цвета**: Элегантный темно-синий (#2C3E50) и серо-синий (#34495E)
- **Акцентные цвета**: Благородный красный (#E74C3C) и золотистый (#F39C12)
- **Фон**: Градиентный переход от фиолетового к синему
- **Текст**: Контрастные оттенки для отличной читаемости

### Типографика
- **Заголовки**: Playfair Display (элегантный serif)
- **Основной текст**: Inter (современный sans-serif)
- **Иерархия**: Четко выстроенная типографическая система

### Визуальные эффекты
- Плавные переходы между слайдами
- Тонкие анимации иконок (gentle-float, gentle-pulse)
- Элегантные тени и скругления
- Градиентные элементы и прогресс-бар

## 🎯 Функциональность

### Интерактивная навигация
- **Кнопки**: Стильные кнопки навигации с hover-эффектами
- **Клавиатура**: 
  - `← →` / `↑ ↓` - навигация по слайдам
  - `Пробел` - следующий слайд
  - `Home` / `End` - переход к началу/концу
  - `Esc` - возврат к титульному слайду
- **Жесты**: Улучшенная поддержка свайпов на мобильных устройствах
- **Прогресс**: Элегантный индикатор прогресса

### Адаптивность и доступность
- **Респонсивный дизайн**: Идеальное отображение на всех устройствах
- **ARIA-атрибуты**: Полная поддержка скринридеров
- **Семантическая разметка**: Правильная HTML-структура
- **Фокус-управление**: Корректная работа с клавиатурой

## 🚀 Технические особенности

### Производительность
- **Плавные анимации**: CSS transitions и transforms
- **Lazy loading**: Оптимизация загрузки элементов
- **Предзагрузка**: Ресурсы загружаются заранее
- **Debounced events**: Оптимизированная обработка событий

### Кроссбраузерность
- Современные браузеры (Chrome, Firefox, Safari, Edge)
- Мобильные браузеры (iOS Safari, Chrome Mobile)
- Fallback для старых браузеров

### SEO и метаданные
- Правильные meta-теги
- Структурированные данные (JSON-LD)
- Оптимизированные заголовки страниц

## 🎮 Управление презентацией

### Основные действия
- **Запуск**: Кнопка "Начать викторину" на титульном слайде
- **Навигация**: Кнопки "Назад"/"Далее" или клавиши
- **Перезапуск**: Кнопка "Начать заново" на финальном слайде

### Индикаторы состояния
- **Прогресс-бар**: Визуальный индикатор прогресса
- **Счетчик слайдов**: "X из Y" в нижней панели
- **Заголовок страницы**: Динамически обновляется
