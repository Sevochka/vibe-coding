# Micro Habit Tracker

Простое одностраничное приложение для трекинга до 7 ежедневных привычек с сериями и мини-графиками. Лёгкий интерфейс в спортивном стиле.

## Описание
- Отмечайте выполнение привычек за день одним кликом (Пропущено → Выполнено → Пропуск).
- Счётчик серии (streak) не сбрасывается на «Пропуск».
- Мини-графики (sparkline) показывают динамику по последним 14 дням.
- Импорт/экспорт в JSON для переноса данных.
- Демо-данные включены по умолчанию.
- Поддержка ноутбуков и мобильных (макс. ширина 660px).

## Фичи
- Добавление, редактирование и удаление привычек (до 7).
- Ежедневные отметки с 3 состояниями: выполнено, пропуск (не ломает серию), пропущено.
- Счётчик серии и мини-графики по дням.
- Экспорт/импорт JSON.
- Авто-ресайз для iframe.
