# Otello Homepage Prototype

## Описание

Современный прототип главной страницы сайта бронирования отелей Otello.ru, созданный на основе анализа макета Figma. Проект представляет собой адаптивный интерфейс с современным дизайном в спортивном стиле, соответствующий брендбуку Sports.ru.

## Особенности

### Дизайн и UI/UX
- **Современный интерфейс** с использованием фирменных цветов Sports.ru
- **Адаптивный дизайн** для всех устройств (максимальная ширина 660px)
- **Градиентные фоны** и тени для создания глубины
- **Интерактивные элементы** с плавными анимациями
- **Типографика** с фирменными шрифтами Roboto и Sports

### Функциональность
- **Форма поиска отелей** с валидацией полей
- **Интерактивные карточки предложений** с hover-эффектами
- **Система избранного** для отелей
- **Анимированные кнопки** с ripple-эффектом
- **Скрывающийся хедер** при прокрутке вниз
- **Динамические даты** в форме поиска

### Секции страницы
- **Хедер** с навигацией и кнопками действий
- **Hero-секция** с главным заголовком и формой поиска
- **Блок преимуществ** сервиса
- **Секция предложений** с промокодами и скидками
- **Суперцены** с карточками отелей

### Интерактивные элементы
- Анимация при наведении на карточки отелей
- Изменение состояния кнопок избранного
- Валидация формы поиска
- Плавные переходы и анимации
- Ripple-эффект на кнопках

## Технические особенности

- **Чистый HTML, CSS, JavaScript** без фреймворков
- **CSS Custom Properties** для управления цветовой схемой
- **Flexbox** для адаптивной верстки
- **CSS Grid** для сложных макетов
- **Intersection Observer API** для оптимизации анимаций
- **Event Delegation** для эффективной обработки событий

## Файлы проекта

- `index.html` - основная HTML структура
- `styles.css` - стили с использованием брендбука Sports.ru
- `script.js` - интерактивность и анимации
- `resize.js` - скрипт для корректного отображения в iframe
- `README.md` - документация проекта

## Использование

Откройте `index.html` в браузере для просмотра прототипа. Все стили и скрипты подключаются локально, интернет требуется только для загрузки шрифтов.

## Брендинг

Проект использует фирменную цветовую палитру и типографику Sports.ru:
- Основной цвет: `#00c78b` (мятный зеленый)
- Дополнительные цвета: синий, фиолетовый, желтый
- Шрифты: Sports для заголовков, Roboto для текста
