# Winline — Топ‑матчи сегодня | интерактивный баннер

Лёгкий проект‑баннер в спортивном стиле с акцентом на просмотр матчей в Winline. Содержит интерактивные карточки матчей, обратный отсчёт до начала и выделение «горячего» коэффициента.

## Описание
- Баннер аккуратно вписывается в ленту (max‑width 660px).
- Поддерживает кликабельные карточки матчей и CTA «Смотреть бесплатно».
- Отображает таймер до начала встречи, усиливая мотивацию кликнуть.
- Использует фирменные шрифты и цвета Sports.

## Возможности
- Интерактивные котировки с подсветкой самого высокого значения.
- Автопересчёт обратного отсчёта каждые 30 секунд.
- Ресайзер `resize.js` для корректной интеграции в iframe.

## Структура
- `index.html` — корневой документ проекта.
- `styles.css` — стили в спортивном стиле.
- `script.js` — логика баннера и отрисовка матчей.
- `data/matches.js` — демо‑данные матчей.
- `resize.js` — авто‑ресайз для встраивания в пост.
